## 🛠️ Step-by-Step Generation & Chaining Workflow

### 1. The Seam Rule: Extracting Real Boundary Frames
To guarantee **zero pops or cuts** between video clips, each video leg must start from the **actual last frame of the previous render**:

```bash
# Extract the exact last frame of Leg 1 to start Leg 2
ffmpeg -sseof -0.15 -i leg1_aerial_entrance.mp4 -frames:v 1 -q:v 2 leg1_last.png

# Extract the exact last frame of Leg 2 to start Leg 3
ffmpeg -sseof -0.15 -i leg2_entrance_corridor.mp4 -frames:v 1 -q:v 2 leg2_last.png

# Extract the exact last frame of Leg 3 to start Leg 4
ffmpeg -sseof -0.15 -i leg3_corridor_bedroom.mp4 -frames:v 1 -q:v 2 leg3_last.png

# Extract the exact last frame of Leg 4 to start Leg 5
ffmpeg -sseof -0.15 -i leg4_bedroom_bathroom.mp4 -frames:v 1 -q:v 2 leg4_last.png

# Extract the exact last frame of Leg 5 to start Leg 6
ffmpeg -sseof -0.15 -i leg5_bathroom_veranda.mp4 -frames:v 1 -q:v 2 leg5_last.png
```

### 2. Rendering CLI Command (Monid / Seedance 2.0 or Higgsfield)
```bash
# Example generating with Higgsfield CLI:
higgsfield generate create seedance_2_0 \
  --prompt "$(cat leg_prompt.txt)" \
  --start-image previous_leg_last_frame.png \
  --mode std \
  --resolution 1080p \
  --aspect_ratio 16:9 \
  --duration 8 \
  --wait --json > leg_result.json
```

### 3. Web Encoding for 60 FPS Canvas Scrubbing
When converting the final video clips into frames or seekable web MP4s:
```bash
# Extract frames at 60 FPS or optimal sequence
ffmpeg -i leg_final.mp4 -vf "fps=30" -q:v 3 frame-%03d.jpg
```
